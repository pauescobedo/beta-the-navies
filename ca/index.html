The band

Set músics.
Un sol corrent.

Som set joves apassionats per la música, units per les ganes de tocar, aprendre i gaudir junts sobre l’escenari. Cada veu i cada instrument formen part de The Navies amb el mateix pes.

En aquest camí comptem amb la col·laboració de BCN Fusió, que ens acompanya i ens ajuda a continuar creixent com a banda.
