# The Navies

Somos siete músicos jóvenes unidos por las ganas de tocar, compartir escenario y hacer que cada concierto se disfrute desde la primera canción. Nuestro repertorio mezcla clásicos del rock, grandes canciones pop y temas reconocibles, llevados a un directo cercano, enérgico y pensado para cantar juntos.

Esta es la web oficial de **The Navies**.

## Inicio

El punto de encuentro con la banda. Aquí puedes descubrir nuestro sonido, conocer la formación, consultar los próximos conciertos y contactar con The Navies.

## Navies Live

Nuestro espacio audiovisual. Próximamente reunirá actuaciones y momentos de nuestros conciertos para volver a vivir la música desde cualquier lugar.

## Espacio Navy

El área privada de la banda, creada para mantener organizados los repertorios, las partituras, los audios y las fechas importantes de cada concierto.
